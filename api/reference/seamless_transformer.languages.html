seamless_transformer.languages

Registries and helpers for languages accepted by Seamless transformers.

python and bash are the built-in native languages. Register compiled languages with define_compiled_language and languages executed by Python handlers with register_language_handler. available_languages() returns each language accepted by the Transformer factory and its kind ("native", "compiled" or "handler"). A language name belongs to one kind.

Built-in compiled languages and the r and julia handlers register when this module is imported. Registration does not import or start R or Julia, or load ryp or juliacall.

run_in_interpreter_thread() runs a callable on one process-wide thread associated with its name, for embedded interpreters that need a stable calling thread. Calls from that thread run inline.

define_compiled_language

  • kind: function
  • signature: define_compiled_language(name, compilation)

Register a compiled language definition.

compilation is a dict with the following keys:

  • compiler (str): the compiler binary name (e.g. "gcc").
  • mode (str): "object" (produces .o), "archive" (produces .a), or "package" (multi-file package compiled to .a, e.g. Go).
  • include_flag (str): flag used to pass the build include directory to the compiler (e.g. "-I" for gcc/gfortran); empty string disables include-dir injection. Defaults to "-I".
  • extension (str): source-file extension required by the compiler (e.g. "go"); empty string falls back to "code".
  • options (list[str]): default (profile/release) compiler flags.
  • debug_options (list[str]): flags used for debug builds.
  • profile_options (list[str]): extra flags added on top of options for profile target.
  • release_options (list[str]): flags used for release builds.
  • compile_flag (str): flag that means "compile only, no link" (e.g. "-c" for gcc).
  • output_flag (str): flag for the output file (e.g. "-o").
  • language_flag (str): flag to tell the compiler which language to use (e.g. "-x c" for gcc); empty string if not needed.

Raises ValueError if mode is not "object", "archive" or "package".

register_language_handler

  • kind: function
  • signature: register_language_handler(name, handler, *, metavars)

Register a Python function as the executor for a transformer language.

The name must not be native or compiled. handler must be one named, source-retrievable function without a closure. Its supported parameters are passed by keyword. metavars maps setting names to their defaults. Registering the same handler language again replaces its registration.
