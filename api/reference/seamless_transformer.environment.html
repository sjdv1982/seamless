seamless_transformer.environment

Execution environment for transformer calls.

Environment

  • kind: class
  • signature: Environment

Execution environment for an individual transformer.

Controls the conda environment, Docker container, and required binaries for the transformation worker. CLI backends enter the selected conda environment or container image. In-memory backends require their process to already be in the requested conda environment and reject Docker.

Access via transformer.environment on any :class:~seamless_transformer.transformer_class.Transformer or :class:~seamless_transformer.compiled_transformer.CompiledTransformer::

tf.environment.set_conda_env("myenv")
tf.environment.set_docker({"name": "my-image:latest"})

A fresh Environment() with no settings contributes nothing to the transformation — all methods accept None to clear a previously set value.

Properties (set/get pairs):

  • conda: a conda environment YAML spec (string, path, or file object). The YAML must be a mapping with a dependencies key.
  • conda_env: the name of an existing conda environment for the bash conda run wrapper.
  • which: binary names checked inside a selected bash conda environment or container image, and on the worker's PATH for other languages.
  • docker: a dict with at least a "name" key specifying the Docker image.

Environment.set_conda

  • kind: method
  • signature: set_conda(self, conda)

Set a conda environment spec from YAML text, a path, or a file object.

The argument may be:

  • a YAML string (must contain dependencies),
  • a file path string or :class:pathlib.Path pointing to a YAML file,
  • a file-like object with a read() method.

Pass None to clear.

Environment.set_conda_env

  • kind: method
  • signature: set_conda_env(self, conda_env_name)

Set a conda requirement or CLI environment for this transformer.

CLI backends enter the environment. In-memory backends require their process to already be running in the specified environment.

Environment.set_docker

  • kind: method
  • signature: set_docker(self, docker)

Set the Docker image and optional runtime settings for this transformer.

The specification is validated when an uncached transformation is dispatched. Pass None to clear.

Environment.set_which

  • kind: method
  • signature: set_which(self, which)

Set binary names whose availability is checked before execution.

CLI backends check inside the selected environment. In-memory backends check the PATH of the process that runs the transformation.

Pass a list of strings (e.g. ["gcc", "make"]) or None to clear.

_validate_environment_dispatch

  • signature: _validate_environment_dispatch(environment)

Validate specifications that make any backend dispatch impossible.
